🧮 Neo Calculator

A modern and responsive calculator built using HTML, CSS, and JavaScript. The project features a sleek glassmorphism design, keyboard support, and basic arithmetic operations for a smooth user experience.

📌 Features
➕ Addition
➖ Subtraction
✖ Multiplication
➗ Division
📊 Percentage Calculation
🗑 Clear Display (C)
⌫ Backspace Function
⌨ Keyboard Support
📱 Fully Responsive Design
🎨 Modern Glassmorphism UI
🚀 Technologies Used
HTML5
CSS3
JavaScript (ES6)
📂 Project Structure
Neo-Calculator/
│
├── index.html
├── style.css
├── script.js

⚙️ Installation
Clone the repository:
git clone https://github.com/yourusername/neo-calculator.git
Open the project folder:
cd neo-calculator
Open index.html in your browser.
🎮 Keyboard Controls
Key	Action
0-9	Enter Numbers
+ - * /	Arithmetic Operations
%	Percentage
Enter	Calculate Result
Backspace	Delete Last Character
Esc	Clear Display
